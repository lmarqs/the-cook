A team keeps two sets of knowledge, prose for people and context files for agents, and the two drift; a fact stated
on several pages goes stale on some of them. Docs gives a repository the `docs-layout` skill, which makes `docs/` the
one tree people and coding agents both read on demand: it teaches where a fact goes and why, writes the map at
`docs/README.md` with the team in its own words, and writes and reviews pages by that map, each fact on one page with
the story behind it.
