## Standards, `ux/`

Holds the rules every interface follows, such as naming, messages and output. Diátaxis type: reference, normative.

- The line after the title states the scope: which interfaces the standard covers.
- Rules use MUST, SHOULD and MAY in capitals, as BCP 14 defines them, and sparingly; the kind's guide states the BCP 14
  sentence once.
- Each rule carries its reason in one sentence, or links the record in `adr/` that holds it.
- A standard is edited in place as its rules change.
