# Standards

Each standard here holds rules every interface in its scope follows. [The map](../README.md) says what belongs here.

The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "NOT
RECOMMENDED", "MAY", and "OPTIONAL" in these standards are to be interpreted as described in BCP 14 (RFC 2119, RFC
8174) when, and only when, they appear in all capitals, as shown here.
