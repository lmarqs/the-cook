# Glossary

For whoever names a thing in larder's code, pages or conversations. It gives each concept its one name. Started when
"member", "user" and "customer" named the same person in three modules.

**Member**:
A person registered with the pantry who orders from it.
_Avoid_: user, customer

**Pantry order**:
The items a member asks for in one checkout, from confirmation until pickup or cancellation.
_Avoid_: purchase, basket

**Capture**:
The gateway charging a card for an amount authorized earlier.
_Avoid_: settlement
