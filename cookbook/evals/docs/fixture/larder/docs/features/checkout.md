# Checkout

For whoever changes how a member confirms a pantry order. A member picks items, reviews the pantry order and
confirms it; confirmation authorizes the card. Written when volunteers kept asking at which step the card is charged.

## Steps

1. The member picks items; the pantry order holds them for the session.
2. The member reviews the pantry order and confirms it; the gateway authorizes the amount.
3. Larder captures the amount, as [payments](payments.md) describes.
